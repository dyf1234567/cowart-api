# Ardot UI Design

Read [core](../ardot-design-core/SKILL.md) first, then the relevant guideline:

| Deliverable | Reference |
|---|---|
| Mobile app / mini app | [Mobile app](references/guidelines-mobile-app.md) |
| Marketing website / landing page | [Landing page](references/guidelines-landing-page.md) |
| Table-heavy interface | [Tables](references/guidelines-table.md) |
| Web app / dashboard / component library / design system | [Web app](references/guidelines-web-app.md) |

Use the user's supplied image or design system as the source of truth. For component variants, variables or shared styles, read the corresponding core guide before editing. Use live Ardot schemas and validate both layout and final visuals.

If frontend implementation is requested, continue with [design to code](../ardot-design-to-code/SKILL.md). Exporting a bitmap preview to Cowart does not preserve editable UI layers.
