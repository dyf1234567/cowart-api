# Ardot Poster

Read [core](../ardot-design-core/SKILL.md) and [poster guidelines](references/guidelines-poster.md). Core's Codex compatibility contract applies to every reference.

Choose a layout contract, palette, font roles, exact type sizes and a single focal point before drawing. Keep critical copy editable, follow the user's language and reference style, and audit every text node and the final screenshot.

For Cowart output, use [cowart-ardot-poster](../cowart-ardot-poster/SKILL.md) as the outer workflow. Reuse its design file and target dimensions; after design validation continue its export/insertion steps. Do not create a second file when loading this skill.

G is placeholder-only on the verified Remote MCP. For real images use an available authorized image workflow, then register_assets/upload_images using live schemas. Never label a placeholder as a completed generated image.

For logos and icons, prioritize a legible focal mark and consistent keylines/strokes. For multiple banner sizes, re-layout per ratio rather than stretching one design.
