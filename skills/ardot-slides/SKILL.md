# Ardot Slides

Read [core](../ardot-design-core/SKILL.md), [slide guidelines](references/guidelines-slides.md), and [slide workflow](workflows/slides-workflow.md). Core's Codex compatibility contract overrides legacy host-specific behavior in references.

Resolve topic, audience, source material, style and slide count from existing context. Write an outline in a task-specific workspace directory. Ask only for consequential missing choices; do not require a second approval of already authorized work.

Use the workflow for outline, layout rhythm, slide construction and final review. Verify that the live schema supports slide nodes before using type slide. If it only supports frames, explain the export limitation and use frames for a design-only deliverable, or the available presentation skill for required PowerPoint output.

Export using actual supported node types and the live export_nodes schema. Do not assume ordinary frames are exported as editable PPTX slides. Import bitmap previews to Cowart only when requested; clearly distinguish these from editable Ardot layers and editable presentation files.
